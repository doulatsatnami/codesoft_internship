# # CodeSoft Internship Projects

This repository contains Machine Learning projects completed as part of the **CodeSoft Internship**.
The projects cover different real-world classification problems using Python, Machine Learning, and Natural Language Processing techniques.

## Projects

### 1. Movie Genre Classification

This project predicts the genre of a movie based on its plot summary or other textual information.
The text data is processed using NLP techniques and converted into numerical features using TF-IDF.
Different classification algorithms are used to train the model and predict the most suitable genre for a movie.

**Techniques:** NLP, TF-IDF, Naive Bayes, Logistic Regression, SVM

---

### 2. Credit Card Fraud Detection

This project focuses on detecting fraudulent credit card transactions from transaction data.
Machine Learning models are trained to classify transactions as either fraudulent or legitimate.
Different classification algorithms are compared to understand their effectiveness in detecting suspicious transactions.

**Algorithms:** Logistic Regression, Decision Tree, Random Forest

---

### 3. Customer Churn Prediction

This project predicts whether a customer is likely to churn or continue using a service.
Historical customer information such as usage behavior, demographics, and account-related features is used for prediction.
Different Machine Learning algorithms are trained and evaluated to identify customers who may be likely to leave.

**Algorithms:** Logistic Regression, Random Forest, Gradient Boosting

---

### 4. Spam SMS Detection

This project classifies SMS messages into Spam or Legitimate categories.
Natural Language Processing techniques are used to clean the messages and extract useful information from the text.
TF-IDF and Machine Learning classifiers are used to identify patterns in messages and predict whether a new SMS is spam.

**Techniques:** NLP, TF-IDF, Naive Bayes, Logistic Regression, SVM
